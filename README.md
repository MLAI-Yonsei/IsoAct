# IsoAct: Geometry-Aware Post-hoc Debiasing via Isometric Actions

Code accompanying the paper. IsoAct performs geometry-aware post-hoc debiasing of representations on hyperspherical, hyperbolic, and SE(3)
manifolds.

## Code

- **Controlled synthetic experiments:** Toy benchmarks on the sphere, hyperbolic space, and SE(3).
  See [controlled_synthetic_benchmark](controlled_synthetic_benchmark/README.md) for execution instructions.

- **Real-world experiments:** IsoAct-FLD implementations for CLIP and MERU embeddings and SE(3) poses, using precomputed representations. See [real_world](real_world/README.md) for input formats and usage.

Please follow the setup and execution instructions in the corresponding directory.
